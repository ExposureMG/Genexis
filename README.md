# Genexis

Heavy WIP

Cross-platform modular Xbox 360 JTAG/RGH toolkit.

Features:

* Fully cross-platform
* NAND Editor and Builder
* BadUpdate / ABadAvatar USB Builder
* Launch.ini, Rgloader.ini & Options.ini editor
* SPI, eMMC, ISD, and XSVF Flashing
* POST and UART Reading
* XeLL, UpdServer, and DashLaunch Network Interaction

# Support

- Windows 10 or Later x64 and arm64
- Linux x86-64 and arm64
- MacOS x86-64 and aarch64
- Android armv8

## Plugin System

Add builders, flashers, or file formats by writing a JSON file.


## Metabuild System

Convert between RGBuild, xeBuild, and Genexis build metadata formats.

Supports converting patches and pre-patching bootloaders.
